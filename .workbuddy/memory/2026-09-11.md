**Confirmed design decisions with the user before testing** (the user overrode the ticket's "required attachment" wording):
- **Attachment slots are advisory only.** Body/source evidence creates a *suggested* slot (`Student CV`) with the best filename candidate; the system must not finalize it. ## Ticket 04: Rewrite preparation with inspectable history (resolved)

Implemented ticket 04 at the same core/CLI seam, TDD red→green per vertical slice. Final run: **81 tests passed, no skips** (63 prior + 17 new in `tests/test_rewrite.py` + 1 new opt-in representative test). The opt-in representative test now runs against `C:\Users\Zeng\Downloads\sample.zip` (the same SHA `f2e73a53…98f5e2` archive; it is NOT bundled in the repo).

**Confirmed design decisions with the user before writing tests:**
- `preparation rewrite PREPARATION_ID --source SOURCE_ID` — prepares a fresh Preparation for the same Outreach Task from a preserved Source Material and marks the prior one Superseded. The source must parse as a supported draft AND its `<Institution>_<Supervisor name>.docx` association must resolve to the same Task.
- Superseded versions are hidden from active views (`preparation list`, `exceptions` findings) and inspected via `preparation history PREPARATION_ID` (version chain newest-first with content, source, association, transformations).
- A new import cannot replace active work: `prepare` records a blocking document finding `replacement_requires_rewrite` (naming the active Preparation) when a draft targets a Task that already has an active Preparation from a *different* Source Material; active work stays untouched. An explicit rewrite clears the finding.

**Implementation**: `preparations` dropped `UNIQUE(task_id, source_id)` and gained nullable `superseded_by TEXT REFERENCES preparations(id)`; `_migrate()` does an idempotent `ALTER TABLE ... ADD COLUMN` so old stores (tickets 01-03 pilots) still open — verified. Active = `superseded_by IS NULL`. `_store_preparation` now reuses only an active Preparation for the same source; new `_insert_preparation` always creates. `get_preparation` gains `status`; new `get_preparation_history`; new core `rewrite`; CLI `preparation rewrite|history`.

**Representative results**: 17 Preparations; revision import of `University of Melbourne_Tessa Laird.docx` → 0 new Preparations + 1 `replacement_requires_rewrite`; rewrite created fresh `e0f616dc…`, superseded corrected/CV-confirmed `84a897b7…`; superseded CV sha `1a04f288…d67e` (28,258 B) still readable; active list stayed 17 across restart.
